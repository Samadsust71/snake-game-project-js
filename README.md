# Snake Game
A classic **Snake Game** implemented using **HTML5 Canvas and JavaScript**. The project is inspired by the nostalgia of playing this game on the Nokia 1100 phone during childhood.

## Only for desktop or laptop

## 🚀 How to Play
1. Use **Arrow Keys** (`⬆️ ⬇️ ⬅️ ➡️`) to move the snake.
2. Eat the **Red Food** to grow the snake and increase the score.
3. Avoid hitting the **walls** or your own body, or it's **Game Over!**
4. Click **New Game** to restart after losing.

Enjoy the game and relive the nostalgia! 🕹️
